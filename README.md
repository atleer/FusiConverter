
# Functional Ultrasound File Merger and Converter

This program makes HDF5 Files from the .mat files supplied by the FUSi system.

View the resulting HDF5 Files at https://myhdf5.hdfgroup.org/

## Setup for Users

Install pixi:

```
winget install prefix-dev.pixi
```

Then just double-click on any of the `.bat` files to run it. 

## Setup for Developers

```
pixi install
```

May need to type:

```
pixi run python -m ipykernel install --name fusi
```
